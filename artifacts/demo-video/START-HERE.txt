REPRODUCE
Run commands from the repository root. Needs Node, Chrome, Playwright, Python 3, and ffmpeg/ffprobe. PLAYWRIGHT_MODULE can point to an existing Playwright index.mjs; CHROME_PATH can point to Chrome.

npm run ui:build
node scripts/build-loop-stories.ts --round prompt:1 --round checks:2 --out artifacts/demo-video/data/stories.json
DEMO_STORIES_FILE=artifacts/demo-video/data/stories.json node src/runner/cli.ts ui --sim --port 4327

In another terminal:
node scripts/video/record.mjs
node scripts/video/github-demo.mjs
node scripts/video/record.mjs setup
node scripts/video/build-project.mjs
python3 scripts/video/assemble.py

The capture script accepts intro, evidence, sip, workflow, or results as its first argument to recapture a section. A workflow recapture creates another labelled simulation run and regression. Do not use a paid live server for this script.

The script builder checks archive hashes. The supplied script uses existing recorded evidence, not a fresh generalization test. Files under frames/, data/, graphics/, and edit-segments/ support reproducibility; the finished edit pack does not require sharing raw experiment archives.
