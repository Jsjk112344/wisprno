# WisprNo UI brand assets

These SVGs and `wisprno.css` are unmodified copies from `WisprNo-Brand-Kit/`. The kit remains the design source. The horizontal dark logo is used in navigation; mono icons adapt to the browser’s light/dark color scheme. Keep the viewBox ratio and the kit’s minimum logo widths.

The React build embeds its logo and icons, so downloaded HTML remains self-contained. The main UI server and standalone Tiger chart serve only the four allowlisted `/brand/` assets. Surface/control styling is in `faultline-ui/src/brand.css`; evidence verdict colors remain separate.
